# Ремонт Хаты

Простая смета ремонта на HTML, CSS и JavaScript, без зависимостей и сервера. Откройте `index.html` или используйте GitHub Pages.

## Возможности

- Материалы и работы, 9 категорий, поиск, статусы, добавление/редактирование/удаление.
- Итоги по категориям и всей смете; отдельная сумма купленного.
- Пустые количества и цены не включаются в сумму. Нулевая цена допустима для собственного труда.
- Все стартовые цены — предварительные бюджетные ориентиры на 13.10.2026. Количества без замеров оставлены пустыми. Это не монтажная документация.
- Изменения сохраняются в localStorage текущего браузера. Нет серверного хранения, аналитики или синхронизации.
- Экспорт/импорт JSON версии 1. Импорт проверяет поля и ссылки, требует подтверждение и сохраняет предыдущую копию локально. Резервная копия находится в том же браузере и не заменяет скачанный JSON.

## GitHub Pages

1. Создайте новый публичный репозиторий `remont_haty` (публичный код для бесплатного Pages).
2. Загрузите `index.html`, `styles.css`, `app.js` и `.nojekyll` в корень ветки `main`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Адрес: `https://<имя-пользователя>.github.io/remont_haty/`.

На GitHub публикуются только исходный код и исходный шаблон сметы. Ваши правки остаются в браузере; не загружайте личные экспортированные JSON в публичный репозиторий.

## Резервное копирование

Нажмите «Экспорт JSON». На другом устройстве откройте тот же сайт и выберите «Импорт». Импорт заменяет текущую смету целиком. Смена домена, браузера, профиля или очистка данных создаёт отдельное хранилище; переносите смету через JSON.

Ссылки в стартовых позициях служат справочными примерами, а не подбором конкретной модели. Все количества и цены можно уточнить.
