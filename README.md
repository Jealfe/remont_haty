# Ремонт Хаты

Небольшой сайт для **предварительной сметы материалов** на ремонт квартиры (~90 м²). Работает на HTML, CSS и JavaScript без сервера и внешних библиотек.

## Что есть

- Фильтр по помещениям: кухня, спальня, две комнаты, два санузла, коридор, кладовая и общие материалы.
- Внутри помещения позиции сгруппированы по видам материалов.
- Таблица: название, параметры, количество, цена за единицу, сумма.
- Сумма по всему списку и выбранному помещению, поиск.
- Добавление, изменение, перенос между комнатами, удаление.
- Пустые количества/цены не входят в итог. Знак `≈` означает предварительную оценку.
- Адаптивный интерфейс для телефона.
- Резервное копирование JSON (экспорт/импорт).

**Не включены в расчёт:** работа мастеров, аренда инструмента, доставка, вывоз мусора. Старые записи, статусы и ссылки не удаляются принудительно из сохранённых пользовательских JSON; они просто не показываются в новой таблице.

## Где хранятся данные

Сайт хранит изменения **только в localStorage того браузера, где вы их внесли**, под ключом `remont-haty-v1`. Это не синхронизация с GitHub или другими устройствами. При очистке данных сайта изменения могут исчезнуть.

Перед изменением браузера/устройства и периодически во время редактирования нажимайте **«Сохранить JSON»** и храните файл отдельно. Импорт JSON заменяет текущую смету только с подтверждением; перед ним сохраняется местная резервная копия.

### Обновление старой сметы

Программа читает JSON версии 1 и сохраняет старые ID, наименования, цены, количества и служебные поля. Отсутствующее поле `room` заполняется безопасным значением «Общие» (некоторые заранее известные светильники и тёплый пол относятся к конкретным помещениям). К старой смете добавляются недостающие справочные позиции по сантехнике и освещению — с неизвестными ценами и количествами, где у нас нет замеров.

При первом сохранении новой версии прежние данные отдельно копируются в `remont-haty-v1-before-rooms`, если такой копии ещё нет. Эта копия тоже хранится **только в браузере**.

## Достоверность исходных данных

Стоимость материалов — предварительный ориентир, а не актуальный прайс. Большинство окончательных количеств потребуют замеров после получения ключей. Проект не заменяет расчёт электрика, проект сантехники, инструкции производителей и исполнительную документацию.

Встроенные световые линии спальни пока запланированы как две линии по 3 м. Для тёплого пола основного санузла предварительная свободная площадь составляет 3,5–4 м², нагрев около 150 Вт/м²; конкретный мат выбирается после раскладки сантехники.

## Публикация

Для GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**. Ожидаемый адрес:
`https://jealfe.github.io/remont_haty/`

Публикация кода не публикует введённые вами локальные данные. Не добавляйте резервные JSON с личными записями в публичный репозиторий.
